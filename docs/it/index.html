Conserva le registrazioni sul telefono e proteggi l’accesso con un PIN o un metodo biometrico supportato. Puoi consultare il codice sorgente per verificare come funzionano l’archiviazione e la crittografia.

Leggi le note sulla sicurezza ↗

Crittografia delle registrazioni

AVault supporta la crittografia AES-256-GCM con chiavi gestite da Android Keystore.

Una serratura tutta tua

Proteggi l’accesso con il PIN dell’app o la biometria supportata. La protezione dello schermo è disponibile nelle impostazioni.

Verifica che una registrazione di prova venga salvata come file .vault. Le limitazioni di archiviazione di Android possono lasciare l’audio non cifrato. La protezione hardware delle chiavi dipende dal dispositivo. Per la riproduzione e la condivisione vengono usati file temporanei decifrati.

Ti serve una mano? ↗
AVault è gratuito e open source?+

Sì. AVault è gratuito e il codice sorgente è pubblico. Il repository contiene un file LICENSE con licenza MIT e avvisi GPL nei file sorgente; consulta le note sulle licenze prima di ridistribuire. Puoi esaminare il codice e contribuire su GitHub.

Devo eseguire il root del telefono?+

No. AVault usa Shizuku per accedere ai servizi di sistema necessari alla registrazione. Durante la configurazione devi avviare Shizuku e concedere le autorizzazioni richieste.

Registra ogni chiamata su qualsiasi telefono?+

Il supporto varia in base al produttore, alla versione Android e all’app per le chiamate. Le app di terze parti possono limitare la registrazione. Fai una prova per verificare la configurazione.

Cosa succede quando condivido una registrazione?+

Condividere una registrazione crittografata crea una copia audio decrittografata per l’app scelta. Questa copia non è protetta dalla cassaforte. Condividi solo con una destinazione di cui ti fidi.

Posso scegliere per quanto tempo conservare le registrazioni?+

Sì. Attiva l’eliminazione automatica e scegli una durata nelle impostazioni. Le registrazioni nei preferiti sono escluse. Puoi anche lasciare disattivata l’eliminazione automatica.
