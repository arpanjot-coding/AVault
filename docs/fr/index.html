02 — UNE CONFIDENTIALITÉ CONCRÈTE

Vos conversations
méritent une porte fermée.

AVault réunit audio chiffré et contrôle d’accès. Le code est ouvert : vous pouvez vérifier ce qui se cache derrière la promesse.

Lire les notes de sécurité ↗

Chiffré au repos

AES-256-GCM protège votre audio lorsque le chiffrement est activé. Les clés sont gérées par Android Keystore.

Votre propre verrou

Protégez l’accès avec un code PIN ou la biométrie prise en charge. La protection de l’écran est disponible dans les paramètres.

La protection matérielle dépend de votre appareil. La lecture et le partage utilisent des fichiers temporaires déchiffrés. Protégez aussi votre appareil.

03 — PRENEZ VOS REPÈRES

Quelques étapes.
Ensuite, à vous de choisir.

AVault utilise Shizuku pour accéder aux services système Android sans root. Configurez la connexion, puis adaptez le coffre à vos besoins.

  1. 01 / TÉLÉCHARGER

    Installez AVault.

    Téléchargez l’APK depuis GitHub Releases et installez-le sur votre téléphone Android.

    Voir les versions ↗
  2. 02 / CONNECTER

    Lancez Shizuku.

    Installez Shizuku, démarrez-le par débogage sans fil ou ADB, puis autorisez AVault.

    Guide de configuration Shizuku ↗
  3. 03 / PERSONNALISER

    À votre manière.

    Suivez la liste des autorisations dans l’application. Choisissez les règles d’enregistrement, le verrouillage et la durée de conservation.

    Guide de configuration ↗

Un mot sur la compatibilité. L’application s’installe sur Android 11 et versions ultérieures. L’enregistrement dépend du téléphone, de la version Android et de l’application d’appel. Shizuku peut nécessiter un redémarrage après celui du téléphone. Testez votre configuration avant de compter sur un enregistrement.

Besoin d’aide ? ↗
AVault est-il gratuit et open source ?+

Oui. AVault est gratuit et son code source est disponible sous GNU General Public License v3 ou ultérieure. Vous pouvez examiner le fonctionnement et contribuer sur GitHub.

Faut-il rooter mon téléphone ?+

Non. AVault utilise Shizuku pour accéder aux services système nécessaires à l’enregistrement. Vous devez lancer Shizuku et accorder les autorisations requises pendant la configuration.

Tous les appels sont-ils enregistrables sur tous les téléphones ?+

La prise en charge varie selon le fabricant, la version Android et l’application d’appel. Une application tierce peut elle-même limiter l’enregistrement. Faites un essai pour vérifier votre configuration.

Que se passe-t-il lorsque je partage un enregistrement ?+

Le partage d’un enregistrement chiffré crée une copie audio déchiffrée pour l’application choisie. Cette copie n’est plus protégée par votre coffre. Partagez uniquement avec une destination de confiance.

Puis-je choisir la durée de conservation ?+

Oui. Activez la suppression automatique et choisissez une durée dans les paramètres. Les favoris sont exclus de cette suppression. Vous pouvez aussi laisser la suppression automatique désactivée.
