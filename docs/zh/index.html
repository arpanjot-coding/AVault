需要帮助？ ↗
AVault 免费且开源吗？+

是的。AVault 可免费使用，源码公开。仓库包含一份 MIT LICENSE 文件，源文件中也有 GPL 声明；再分发前，请阅读许可说明。你可以查阅代码，也可以在 GitHub 上参与贡献。

需要给手机 root 吗？+

不需要。AVault 通过 Shizuku 访问录音所需的系统服务。设置时，需要启动 Shizuku 并授予必要权限。

所有手机上的每一通电话都能录制吗？+

录音支持情况因手机厂商、Android 版本和通话应用而异。第三方通话应用本身也可能限制录音。请先进行测试录音，确认配置可用。

分享录音时会发生什么？+

分享加密录音时，会为你选择的应用生成解密后的音频副本。该副本不再受音频库保护。请仅向可信的目标分享。

可以选择录音保留多久吗？+

可以。在设置中启用自动删除，并选择保留期限。已添加书签的录音不会被自动删除。你也可以关闭自动删除。
