セキュリティの説明を読む ↗

保存時の暗号化

暗号化を有効にすると、AES-256-GCM が音声を保護します。鍵は Android Keystore で管理されます。

自分のためのロック

アプリ専用 PIN または対応する生体認証でアクセスを保護。画面のプライバシー保護も設定できます。

ハードウェアによる保護は端末によって異なります。再生と共有には一時的な復号済みファイルを使用します。端末自体の保護も忘れずに。

お困りですか？ ↗
AVault は無料のオープンソースですか？+

はい。AVault は無料で利用でき、ソースコードは公開されています。リポジトリには MIT の LICENSE ファイルがあり、ソースファイルには GPL の表示もあります。再配布する前にライセンスに関する説明をご確認ください。コードの確認や GitHub での貢献が可能です。

スマートフォンの root 化は必要ですか？+

不要です。AVault は Shizuku を使い、録音に必要なシステムサービスにアクセスします。設定時には Shizuku を起動し、必要な権限を付与してください。

すべてのスマートフォンですべての通話を録音できますか？+

録音への対応はメーカー、Android のバージョン、通話アプリによって異なります。他社製アプリの通話録音は、そのアプリ自体に制限される場合もあります。テスト録音で設定を確認してください。

録音を共有すると、どうなりますか？+

暗号化された録音を共有すると、選択したアプリ向けに復号済みの音声コピーが作成されます。このコピーは保管庫の保護対象外です。信頼できる共有先だけを選んでください。

録音の保存期間を選べますか？+

はい。設定で自動削除を有効にして、保存期間を選べます。ブックマークした録音は自動削除されません。自動削除を無効のままにすることもできます。
