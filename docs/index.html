Designed for Total Privacy & Confidentiality

Built from the ground up to solve the security flaws of traditional recording apps.

🔒

Hardware Cryptographic Vault

Every conversation is sealed using AES-256 in authenticated Galois/Counter Mode (GCM). Master keys are generated inside your device's Hardware Security Module (TEE / StrongBox) and never enter user RAM.

🛡️

Zero-Plaintext Ephemeral Playback

Audio is decrypted strictly on-the-fly in private volatile memory (0600 POSIX permissions). Pausing, stopping, or exiting the app securely shreds the temporary stream instantly.

⚡

Rootless Telephony Capture

Pairs standard Android Telecom state changes with Shizuku's rootless ADB bridge to capture both your voice (uplink) and the remote caller (downlink) cleanly on Android 12 through Android 16+.

⏱️

Auto-Delete with Bookmark Exemption

Set automated retention from 1 day to 1 year to prevent storage waste. Tap the bookmark icon to mark any conversation as permanently saved—bookmarked calls never get purged.

👆

Biometrics & Salted PIN Lock

Protect vault access with your fingerprint scanner, Face Unlock, or an independent PBKDF2/SHA-256 salted PIN with exponential brute-force backoff protection.

🤫

Stealth Mode & FLAG_SECURE

Status alerts use discreet phrasing ("Started", "Saved"). Call-end toast popups are eliminated, and Android's FLAG_SECURE blocks screenshots and task-switcher previews.

Simple 3-Minute Setup

No computer required when using Wireless Debugging on Android 11+.

01

Install AVault APK

Download the pre-compiled APK directly from GitHub Releases and tap Install on your Android device.

02

Start Shizuku

Open Shizuku, pair with on-device Wireless Debugging (Developer Options), and tap Start.

adb shell sh .../start.sh
03

Authorize & Protect

Open AVault, tap "Authorize" on the Shizuku prompt, configure your PIN/Biometrics, and you are ready!
