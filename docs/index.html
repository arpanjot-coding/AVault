High-Assurance Capabilities

Engineered for Uncompromising Privacy

Traditional recording tools write plaintext audio to shared storage. AVault seals every byte inside hardware-backed cryptographic containers.

CRYPTO CORE

Hardware-Backed AES-256-GCM Vault

Master cryptographic keys are generated directly inside your Android processor's Hardware Security Module (TEE or StrongBox Keymaster). Every recording is streamed through authenticated Galois/Counter Mode (GCM) with 128-bit authentication tags, preventing eavesdropping and physical storage tampering.

Encrypted on Disk: .vault Container Zero Root
MEMORY INTEGRITY

Zero-Plaintext In-Memory Playback

Audio is decrypted on-the-fly strictly in private volatile memory. No temporary MP3 or WAV files ever touch disk. Exiting or pausing the player shreds memory buffers with zero residue.

0600 POSIX File Mask ✓ Shredded
PRIVILEGE

Rootless Telephony Capture

Pairs Android Telecom framework state machines with Shizuku's rootless ADB bridge to cleanly record cellular calls and VoIP applications without tripping SafetyNet or Play Integrity.

Automated Retention with Permanent Bookmarking

Quick Start

Up & Running in 3 Minutes

No computer required when pairing directly via Android Wireless Debugging.

01

Install Standalone APK

Download the pre-compiled APK from GitHub Releases and tap to install on your Android 12–16+ device.

AVault-v2.0.0-debug.apk Signed
02

Pair Wireless Debugging

Open Shizuku, pair once via Wireless Debugging in Developer Options, and tap Start.

adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
03

Authorize & Lock Vault

Launch AVault, tap "Authorize" on the Shizuku prompt, configure your Master PIN or Biometrics, and your calls are automatically protected.

AES-256 Keymaster Bound ✓ Ready
