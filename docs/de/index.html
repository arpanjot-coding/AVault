Verschlüsselung der Aufnahmen

AVault unterstützt AES-256-GCM-Verschlüsselung mit Schlüsseln, die der Android Keystore verwaltet.

Ihr eigener Zugangsschutz

Schützen Sie den Zugriff mit einer App-PIN oder unterstützter Biometrie. Den Bildschirmschutz finden Sie in den Einstellungen.

Prüfen Sie, ob eine Testaufnahme als .vault-Datei gespeichert wird. Android-Speicherbeschränkungen können dazu führen, dass die Audiodatei unverschlüsselt bleibt. Hardwaregestützter Schlüsselschutz hängt vom Gerät ab. Für die Wiedergabe und das Teilen werden vorübergehend entschlüsselte Dateien verwendet.

Brauchen Sie Hilfe? ↗
Ist AVault kostenlos und Open Source?+

Ja. AVault ist kostenlos und der Quellcode ist öffentlich. Das Repository enthält eine MIT-LICENSE-Datei und GPL-Hinweise in Quelldateien; lesen Sie vor einer Weiterverbreitung die Lizenzhinweise. Sie können den Code prüfen und auf GitHub mitarbeiten.

Muss mein Telefon gerootet sein?+

Nein. AVault nutzt Shizuku für den Zugriff auf die zur Aufnahme benötigten Systemdienste. Bei der Einrichtung müssen Sie Shizuku starten und die erforderlichen Berechtigungen erteilen.

Funktioniert die Aufnahme bei jedem Anruf auf jedem Telefon?+

Die Unterstützung unterscheidet sich je nach Hersteller, Android-Version und Anruf-App. Drittanbieter-Apps können die Aufnahme selbst einschränken. Bestätigen Sie Ihre Konfiguration mit einer Testaufnahme.

Was passiert, wenn ich eine Aufnahme teile?+

Beim Teilen einer verschlüsselten Aufnahme entsteht eine entschlüsselte Audiokopie für die ausgewählte App. Diese Kopie liegt außerhalb des Tresorschutzes. Teilen Sie nur mit einem Ziel, dem Sie vertrauen.

Kann ich die Aufbewahrungsdauer selbst wählen?+

Ja. Aktivieren Sie das automatische Löschen und wählen Sie die Dauer in den Einstellungen. Aufnahmen mit Lesezeichen sind davon ausgenommen. Sie können das automatische Löschen auch deaktiviert lassen.
