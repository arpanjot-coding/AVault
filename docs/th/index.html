โอเพนซอร์ส ในแบบที่คุณเลือก

บันทึกเสียงการโทรบน Android
ไม่ต้องรูท

ใช้ Shizuku บันทึกเสียงการโทรบนโทรศัพท์ Android ที่รองรับ ค้นหาไฟล์บันทึกตามรายชื่อผู้ติดต่อ คั่นหน้าสายสำคัญ และกำหนดเวลาลบไฟล์บันทึกเก่าได้

ดาวน์โหลดสำหรับ Androidรู้จักคลังของคุณ ↘

ใช้งานฟรี · Android 11 ขึ้นไป · ต้องใช้ Shizuku

เข้ารหัส AES-256-GCMซอร์สโค้ดที่คุณตรวจสอบได้

01 — พื้นที่สำหรับบทสนทนาของคุณ

ค้นหาน้อยลง
จดจำได้มากขึ้น

ตั้งแต่รายละเอียดที่เป็นประโยชน์ไปจนถึงการตัดสินใจสำคัญ ค้นหาบทสนทนาที่ต้องการได้โดยไม่ต้องไล่เปิดไฟล์เสียงทั้งโฟลเดอร์

01

ค้นหาช่วงเวลาที่ต้องการ

ค้นหาจากรายชื่อผู้ติดต่อ หมายเลข หรือแอป ใช้ตัวกรองเพื่อเข้าถึงบันทึกเสียงที่ต้องการได้ทันที

02

เก็บสิ่งสำคัญไว้

บุ๊กมาร์กบันทึกเสียงเพื่อยกเว้นจากการล้างไฟล์อัตโนมัติ ส่วนไฟล์อื่นให้เป็นไปตามระยะเวลาเก็บที่คุณเลือก

03

ฟังอีกครั้ง แล้วไปต่อ

เล่นบันทึกเสียงภายในคลัง พร้อมปุ่มควบคุมที่ใช้งานได้สะดวก เลือกแชร์สำเนาเสียงได้เมื่อต้องการ

สำรวจคุณสมบัติ ↗

02 — ความเป็นส่วนตัวที่มีหลักการรองรับ

บทสนทนาของคุณ
ควรมีพื้นที่ส่วนตัว

เก็บไฟล์บันทึกไว้ในโทรศัพท์และป้องกันการเข้าถึงด้วย PIN หรือการยืนยันตัวตนด้วยข้อมูลชีวมิติที่อุปกรณ์รองรับ คุณดูวิธีจัดเก็บและเข้ารหัสได้จากซอร์สโค้ด

อ่านบันทึกด้านความปลอดภัย ↗

การเข้ารหัสไฟล์บันทึก

AVault รองรับการเข้ารหัส AES-256-GCM โดยใช้คีย์ที่จัดการผ่าน Android Keystore

ล็อกในแบบของคุณ

ปกป้องการเข้าถึงด้วย PIN ของแอปหรือการยืนยันตัวตนด้วยไบโอเมตริกที่รองรับ เปิดการปกป้องเนื้อหาบนหน้าจอได้ในการตั้งค่า

ตรวจสอบว่าไฟล์บันทึกทดสอบถูกบันทึกเป็นไฟล์ .vault ข้อจำกัดด้านพื้นที่เก็บข้อมูลของ Android อาจทำให้ไฟล์บันทึกไม่ได้รับการเข้ารหัส การปกป้องคีย์ด้วยฮาร์ดแวร์ขึ้นอยู่กับอุปกรณ์ และการเล่นหรือแชร์ใช้ไฟล์ที่ถอดรหัสชั่วคราว

สำหรับงานที่ควรค่าแก่การจดจำ

เก็บทุกรายละเอียดไว้

03 — ตั้งค่าให้เข้ากับคุณ

เพียงไม่กี่ขั้นตอน
จากนั้นคุณเป็นผู้เลือก

AVault ใช้ Shizuku เพื่อเชื่อมต่อบริการระบบของ Android โดยไม่ต้อง root ตั้งค่าให้พร้อม แล้วปรับคลังให้เหมาะกับคุณ

  1. 01 / ดาวน์โหลด

    รับ AVault

    ดาวน์โหลด APK จาก GitHub Releases แล้วติดตั้งบนโทรศัพท์ Android ของคุณ

    ดูรุ่นที่เผยแพร่ ↗
  2. 02 / เชื่อมต่อ

    เริ่ม Shizuku

    ติดตั้ง Shizuku แล้วเริ่มการทำงานผ่านการแก้ไขข้อบกพร่องแบบไร้สายหรือ ADB จากนั้นอนุญาตให้ AVault ใช้งาน

    คู่มือตั้งค่า Shizuku ↗
  3. 03 / ปรับให้เหมาะกับคุณ

    ตั้งค่าตามที่คุณต้องการ

    ทำตามรายการสิทธิ์ในแอป เลือกกฎการบันทึก ล็อกแอป และระยะเวลาเก็บไฟล์

    คู่มือตั้งค่า Android ทีละขั้นตอน (ภาษาอังกฤษ) ↗

ข้อควรรู้เรื่องความเข้ากันได้ ติดตั้งแอปได้บน Android 11 ขึ้นไป การบันทึกการโทรขึ้นอยู่กับโทรศัพท์ เวอร์ชัน Android และแอปที่ใช้โทร อาจต้องเริ่ม Shizuku อีกครั้งหลังรีสตาร์ตเครื่อง ทดสอบการตั้งค่าก่อนนำไปใช้กับการบันทึกที่สำคัญ

ต้องการความช่วยเหลือไหม? ↗
AVault ฟรีและเป็นโอเพนซอร์สหรือไม่?+

ใช่ AVault ใช้งานได้ฟรีและเปิดเผยซอร์สโค้ด ที่เก็บโค้ดมีไฟล์ LICENSE แบบ MIT และมีประกาศ GPL ในไฟล์ซอร์สโค้ด โปรดอ่านหมายเหตุเรื่องสัญญาอนุญาตก่อนแจกจ่ายต่อ คุณตรวจสอบโค้ดและร่วมพัฒนาได้บน GitHub

ต้อง root โทรศัพท์หรือไม่?+

ไม่ต้อง AVault ใช้ Shizuku เพื่อเข้าถึงบริการระบบที่จำเป็นสำหรับการบันทึก คุณต้องเริ่ม Shizuku และให้สิทธิ์ที่จำเป็นระหว่างการตั้งค่า

บันทึกทุกสายบนโทรศัพท์ทุกรุ่นได้หรือไม่?+

การรองรับการบันทึกแตกต่างกันตามผู้ผลิต เวอร์ชัน Android และแอปที่ใช้โทร การบันทึกสายจากแอปอื่นอาจถูกจำกัดโดยแอปนั้นเอง ควรทดลองบันทึกเพื่อยืนยันว่าการตั้งค่าทำงานได้

เกิดอะไรขึ้นเมื่อแชร์บันทึกเสียง?+

การแชร์บันทึกเสียงที่เข้ารหัสจะสร้างสำเนาเสียงที่ถอดรหัสแล้วสำหรับแอปที่คุณเลือก สำเนานี้อยู่นอกการปกป้องของคลัง แชร์ไปยังปลายทางที่คุณไว้วางใจเท่านั้น

เลือกระยะเวลาเก็บบันทึกเสียงได้หรือไม่?+

ได้ เปิดการลบอัตโนมัติและเลือกระยะเวลาเก็บในการตั้งค่า บันทึกเสียงที่บุ๊กมาร์กจะไม่ถูกลบอัตโนมัติ หรือจะปิดการลบอัตโนมัติไว้ก็ได้
