How to record calls on Android without root

AVault uses Shizuku to record calls on compatible Android phones. Follow these steps to install the APK, start Shizuku and check that your phone can capture the audio you need.

On this page

  • Install and set up
  • Make a test recording
  • Record selected calls
  • Troubleshooting

What you need

AVault installs on Android 11 or later and requires a running Shizuku service. Recording support depends on your phone, Android build and calling app. On Android 11, use Phone State detection. InCallService is available from Android 12 when the required permissions are available.

Use AVault for lawful research, education and evaluation with the consent required for your call. See the intended use and disclaimer.

Install AVault and start Shizuku

  1. Install the APK. Open the latest AVault release and choose the APK under Assets. Android may ask you to allow installation from the app opening the file. To update an existing vault in place, use an APK signed with the same key.
  2. Start Shizuku. Install Shizuku from its official distribution. On Android 11 and later, follow the Shizuku wireless debugging instructions to pair it and tap Start. If you’re using a computer, open View command in Shizuku and use the ADB command displayed by your installed version.
  3. Complete AVault’s permission checklist. Open AVault, allow its Shizuku request and enable notifications. Follow the checklist for battery optimisation and the permissions required by your chosen call detection method.

Make a test recording

Make a short call with someone who agrees to the recording. Look for AVault’s recording notification. When the call ends, open the library, play the saved recording and check that both sides are audible. Repeat the test for each calling app you plan to use.

If you enable encryption, check that your test recording saves as a .vault file before relying on encrypted storage. Android denied that write in shared storage during testing on an Android 16 emulator, and the app retained the unencrypted audio.

Record only the calls you choose

In the published app, open Settings → Recording and turn off automatic recording for incoming and outgoing calls. During a detected call, tap Start in the AVault notification to begin recording. The recording saves when you hang up.

Troubleshoot call recording

The notification doesn’t appear
Confirm Shizuku is running and AVault is authorised. Check Android’s notification settings and the app’s call detection permissions. Restart Shizuku after a reboot if it stopped.
The file is silent or only one side is audible
Test a regular carrier call first. Review the audio source in AVault’s Audio configuration, then try another short call. Phone manufacturers and calling apps can restrict which audio is available.
An APK update fails to install
Check that the APK matches the signing key used for the installed app. Keep the existing app and your recordings in place while you check the update notes.

For more detail, see the configuration guide or report a reproducible issue with your device, Android version and call detection method.
